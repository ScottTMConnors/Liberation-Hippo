# 1.1.40

## 🖼️ Server browser
- Selecting Hippos Conquest in the server browser or lobby now shows its picture and a short description.

## 🎨 Icons
- New reputation faces on the HUD, from a red frown to a green smile.
- New notification badges: green when a sector is captured, red when something is lost, blue for friendly news and amber for warnings.
- Cleaner action icons with subtle colors, such as green for confirm, red for cancel and amber for build.

## 🛠️ Build menu
- The "Active units" line turns red when you reach the unit cap.

## 🧹 Cleanup
- Removed old, unused images from the mission.
