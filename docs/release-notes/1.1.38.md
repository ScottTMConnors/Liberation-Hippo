# 1.1.38

## 🛠️ Build menu
- "Add AI crew" is now a checkbox that shows on every vehicle and defense page. Commanders can tick it; other players see it grayed out.
- Each line of the cost table has its resource icon.
- The vehicle stats show fuel capacity without a misleading unit.

## 🎨 New resource icons
- Manpower, ammo and fuel have new, cleaner icons everywhere they appear.

## 🛡️ Admin menu
- The admin menu is split into World, Campaign, Players and Tools tabs, with the active tab highlighted.
- Players are shown as a list with their online or offline status instead of a dropdown.
- Mission admin, AI load, Player permissions, Mission settings and FOB template are buttons in the admin menu instead of separate scroll-menu actions.
- The mission admin menu no longer closes itself a split second after opening.
- The mission admin menu lists side missions by their real names.
- The permissions screen is now called Player permissions and explains that it sets server-wide rules for each player.

## 📋 Action menu
- Every action uses the same style and sentence case, including towing, lifting and loading actions.
- Clearer wording for many actions, such as "Remove fortifications", "Add fuel", "Plant sticky bomb" and "Climb aboard".

## 🎯 Side missions
- Delivery and Resistance missions name their contact with a random rank and name, like "Captain Miller", instead of "Nikos" or "the Marshal".

## ✏️ Text
- Player-facing text uses American English spellings.

## 🖼️ Mission browser
- The mission picture uses a smaller image so it loads in the mission browser.
